# Data Structures in Java

> Class Project · CSC 172, University of Rochester

A semester of data-structure implementations in Java, one lab at a time — each with its own implementation and test class.

## What It Covers

| Lab | What it implements |
| --- | --- |
| Lab 1 | Introductory lab |
| Lab 2 | TwoSum / ThreeSum and a Stopwatch for timing |
| Lab 3 | Sorting algorithms |
| Lab 4 | `URLinkedList` — a linked list |
| Lab 5 | `URLinearProbingHashTable` — a hash table with linear probing |
| Lab 6 | `MyBST` — a binary search tree |
| Lab 7 | Heap |

## Tech Stack

Java · Linked lists · Hash tables · Binary search trees · Heaps · Sorting

## How to Run

```bash
# Compile and run one lab's test class, e.g. Lab 5
cd Lab5_CZ
javac *.java
java URLinearProbingHashTableTest
```

The Princeton standard library helpers (`In.java`, `StdOut.java`, `StdRandom.java`) in Lab 2 are shared dependencies for the labs — keep them on the classpath when compiling.

## Files

Organized by lab folder (`Lab1`, `Lab2_CZ`, `Lab3_CZ`, `Lab4_CZ`, `Lab5_CZ`, `Lab06_CZ`, `Lab7_CZ`), each with its implementation and test files.
